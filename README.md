# Elmos Yar: Intelligent University Professor Analysis System

**Elmos Yar** is a comprehensive Data Mining and AI project designed to analyze student feedback, classify professor performance, and recommend the best courses based on personalized student needs.

Using **Deep Learning (BERT)** for sentiment analysis and **Unsupervised Machine Learning (K-Means)** for profiling, this system transforms unstructured Persian student comments into actionable insights.

---

## Key Features

* **Advanced Sentiment Analysis:** Utilizes **ParsBERT** (Transformer model) to achieve **89% accuracy** in detecting nuanced student sentiment (Positive/Negative) in Persian text, outperforming traditional lexicon methods.
* **Intelligent Profiling:** Automatically groups professors into archetypes (e.g., "Strict but Effective," "Popular & Easy," "Low Quality") using **K-Means Clustering** and PCA visualization.
* **Hybrid Recommender System:** A "Netflix-style" engine that suggests professors based on:
    * **Similarity:** "If you liked Prof A, you will like Prof B."
    * **Content Filtering:** "Find me a Project-Based professor who is Chill about attendance."
* **Insightful Visualization:** Detailed charts showing the correlation between teaching quality, morality, and grading fairness.

# How to Run the AI Model (ParsBERT)
This project uses the HooshvareLab/bert-fa-base-uncased-sentiment-digikala model.

**Recommended Method (Automatic):** Simply run **Notebook 04 (04_bert_sentiment.ipynb).**

* The code includes an auto-downloader that will fetch the model (~450MB) from Hugging Face if it detects the models/ folder is empty.

* *Note:* The first run may take 5-10 minutes depending on your internet speed.

**Manual Method (Only if Automatic fails):**

1. Download 'pytorch_model.bin', 'config.json', and 'vocab.txt' from [Hugging Face](https://huggingface.co/HooshvareLab/bert-fa-base-uncased-sentiment-digikala/tree/main).

2. Place them in: 'models/parsbert_sentiment/'.
